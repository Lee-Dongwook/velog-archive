### 테스트 자동화의 효과, 리스크

테스트 자동화가 가져올 수 있는 효과

- 반복적 수작업을 줄여 시간 절약
- 일관성 및 재현성 향상 -> 사람의 단순 실수 방지
- 보다 객관적 평가 가능
- 사람이 판단하기 어려운 복잡한 측정치의 제공
- 결함 조기 식별 / 빠른 피드백 / 출시 시간 단축 가능하게 하는 테스트 실행 시간 단축
- 테스트 관리 및 보고를 지원하기 위한 테스팅 정보에 더 쉽게 접근 가능
- 테스터가 새롭고, 더 심층적이고, 효과적인 테스트 설계할 시간 확보해줌.

but, 도구를 도입한다고 꼭 성공이 보장되는건 아님.
실질적이고 지속적인 효과를 위해서는 도구 도입 시 노력이 필요하고,
분석과 완화가 필요한 리스크도 있음.

테스트 자동화 활용시의 리스크

- 도구의 효과에 대한 비현실적 기대감
- 도구 도입, 테스트 스크립트 유지 관리, 기존 수동 테스트 프로세스 변경에 드는 시간, 비용, 노력에 대한 부정확한 추정
- 수동 테스팅이 더 적합한 곳이 있을 수 있음
- 도구에 지나치게 의존
- 폐업 / 도구 지원 중단 / 도구 매각 등 문제가 생길 수 있는 도구 공급업체에 대한 종속성
- 자동화 도구가 개발 플랫폼과 호환되지 않을 수 있음
- 규제 / 안전 표준을 준수하지 않는 부적합 도구일 수 있음.

### 테스팅 지원 도구

- 테스트 관리 도구 : SDLC, 요구사항, 테스트, 결함, 형상 관리를 용이하게 함
- 정적 테스팅 도구 : 테스터의 리뷰와 정적 분석 수행을 지원
- 테스트 설계 & 테스트 구현 도구 : 테스트 케이스, 테스트 데이터, 테스트 절차 생성 용이
- 테스트 실행 & 테스트 커버리지 도구 : 자동 테스트 실행 및 커버리지 측정 지원
- 비기능 테스팅 도구 : 수동으로 실행이 어렵거나 불가능한 비 기능 테스트를 수행 가능
- 데브옵스 도구 : 데브옵스 배포 파이프라인, 작업 흐름 추적, 자동 빌드 프로세스, 지속적 통합 배포 지원
- 협업 도구 : 원활한 커뮤니케이션
- 확장성 및 배포 표준화 지원 도구 : 가상 머신 , 컨테이너화 도구
- 기타 : 스프레드시트 등
